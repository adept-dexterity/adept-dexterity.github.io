# ADEPT media

Place optimized project videos in this directory. MP4 with H.264 encoding is the
most broadly compatible format for GitHub Pages.

Replace a placeholder in `index.html` with:

```html
<video autoplay muted loop playsinline poster="media/example-poster.webp">
  <source src="media/example.mp4" type="video/mp4" />
</video>
```

Keep the existing `.media-placeholder` wrapper if you want to preserve the card
layout, labels, and rounded play control.
